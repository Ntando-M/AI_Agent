AI Data Analyst — V10 Architecture

Two front doors, one engine · Python CLI + FastAPI, behind an ASP.NET Core gateway and an Angular 22 client · LangChain · Pandas/SQLite · Chroma RAG · Groq or Ollama — derived from source at HEAD a5ebcf1, not from AGENTS.md prose

Two front doors, three clients, one engine

  • • main.py CLI (337 lines): interactive loop, provider + session selection, /history /clear /exit
  • • api/app.py FastAPI (:8000): 17 routes over health, sessions, chat, analyse, datasets, documents, reports
  • • 16 of those 17 carry Depends(verify_api_key); /health is deliberately open so a probe needs no secret
  • • api-dotnet/ ASP.NET Core gateway (:5000, net8.0): proxies all 17 routes, attaches X-API-Key from user secrets, and refuses to start without it
  • • web/ Angular 22 SPA (:4200): dev proxy /api → :5000, so the browser bundle never carries the key
  • • Both Python front doors call LLMGateway.build(provider) and hand it to the same Orchestrator; both write through the same SQLiteConversationStore
  • • scripts/run_services.py starts FastAPI, then the gateway, then the web client in health-gated order; restart_services.py frees the ports first

Deterministic core

  • • orchestrator/intent.py → SourcePlan: documents / dataset / database / chart, multi-source
  • • Orchestrator.handle() merges retrieval and analysis, then reconciles what the answer claims against what actually ran
  • • collect_evidence_sources() / apply_evidence(): provenance is built from what was retrieved or executed — a model naming its own tool is not a source, so its claim is discarded
  • • resolve_analysis_type() picks the AnalysisType literal: general / document / dataset / database / visualisation
  • • AnalysisResponse.clamp_confidence() rescales a percentage the model returns (100) into 0.0–1.0 instead of rejecting the whole response
  • • 19 tools: 15 Pandas + 4 read-only SQL, each with a Pydantic input model; a hallucinated tool name cannot add a source or a table
  • • Groq RateLimitError maps to 429 rather than 500; the 1536-token completion cap keeps a planning call inside the free tier
  • • The LLM plans and phrases; Pandas and SQLite compute. No eval, no exec

State and stores

  • • memory/sqlite_store.py: ConversationStore ABC + SQLiteConversationStore, shared by the CLI and the API
  • • chat_history.db: the LangChain-owned message_store plus a nullable evidence column written by a follow-up UPDATE, and a session_catalog with a name column so an empty session is still listable and nameable
  • • Turn.evidence round-trips analysis type, confidence and sources; a row written before evidence existed reads back as None, not as zero confidence
  • • data/sample_sales.xlsx is the working dataset; data/uploads/ is the API upload target, bounded by UploadPolicy (10 MB, extension-checked, git-ignored)
  • • data/sales.db is optional — the SQL tools switch off when it is absent rather than failing the turn
  • • chroma_db/ is an optional Chroma index; without it the API degrades to documents_indexed: false
  • • reports/ holds one JSON file per report — persisted, not in-memory, so a report survives a restart
